# Cozypop Trails Unity Legal Pages

本目录是 GitHub Pages 发布源的一部分，用于 Unity 跨端应用的独立协议页面。

## Public URLs

本目录应通过直接 GitHub Pages 静态页发布。按默认 GitHub Pages 项目页规则，当前生成 URL 为：

- Privacy Policy: `https://luka-king.github.io/arrowpop/cozypop-unity/privacy.html`
- Terms of Service: `https://luka-king.github.io/arrowpop/cozypop-unity/terms.html`
- Support: `https://luka-king.github.io/arrowpop/cozypop-unity/support.html`
- Android store listing: `https://luka-king.github.io/arrowpop/cozypop-unity/marketing.html`

## Scope

- Unity `1.0.0`：只供 Android 提审使用，纯游戏版本，不接 IAA、广告、AppsFlyer、Facebook、Firebase 或其它第三方埋点。
- Unity `2.0.0`：计划开始 Android 和 iOS 同时提审，到时应重新核对协议与实际 SDK/数据行为。
- 原生 iOS 线上 `1.4` 的协议链接保持不动，不要改用本目录。

## Sync Rule

`unity/docs/legal/*.html` 是 Unity 工程内文档副本；本目录是 GitHub Pages 发布副本。修改任一侧时需要保持两边内容一致。
